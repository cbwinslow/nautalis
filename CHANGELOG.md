## [Unreleased]

### Added

- Core memory management system with vector storage support
- Connector framework with pluggable architecture
- Agent orchestration engine for multi-step workflows
- Telemetry and observability layer with OpenTelemetry integration
- Slack connector for message history and channel context
- GitHub connector for repository, issue, and PR context
- Semantic search across all connected data sources
- CLI for managing connectors and memory stores
- REST API for programmatic access to memory and orchestration
- Support for Bun and Node.js runtimes
- Docker Compose setup for local development
- Documentation site with VitePress
